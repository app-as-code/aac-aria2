# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/aria2.svg` | Default (light mode) |
| `icon-light.svg` | `svg/aria2-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/aria2-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/aria2.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/aria2-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/aria2-light.svg

License of the icon collection: CC-BY-4.0 (repository `selfhst/icons`).

The icon depicts the aria2 project, which is the download backend of this deployment.
The logo is the property of the aria2 project (https://aria2.github.io/, GPL-2.0
for the software). Trademark and logo rights remain with the upstream project.
